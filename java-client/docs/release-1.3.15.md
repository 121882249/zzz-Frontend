# TokenPro v1.3.15

- 按磁盘事实模型重构 Codex 渠道切换：快照、凭据、L1/L2 配置、模型缓存、重载、写后校验和失败回滚形成完整事务。
- 官方 OAuth 登录态保存到 TokenPro 私有目录；切换第三方时写入 API-key 形态，切回官方时校验并恢复。
- 使用成对的 `tokenpro-codex` owner 标记，识别并报告其他渠道的活动标记，同时保留所有 Codex L0 用户设置。
- 切换不再删除 TeamoRouter 或其他渠道的服务、认证备份、模型目录、skills 和状态文件，只移除共享配置中的冲突活动路由。
- 渠道状态改为联合读取 `model_provider`、端点和 `auth_mode`，不再使用 TokenPro 上次保存的状态代替磁盘事实。
- 配置、认证、缓存、模型目录和私有状态统一使用 `0600` 原子写；切换失败恢复快照并重启原渠道。
