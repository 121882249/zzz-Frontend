# TokenPro v1.2.99

## 生图模型与路由严格一一对应

- Codex 每次只能应用一款生图模型；文本模型仍可多选。
- 点击另一款生图模型时，自动取消上一款。
- 配置生成和选择状态保存层再次强制收敛为一款，兼容旧版遗留的多选状态。
- Codex 模型目录中只写入已应用的那款生图模型，模型 slug、group_id 与
  `x-tokenpro-image-route` 必须完全一致。
- 更换 Flare、Sunburst 或其他图片模型时，须回到 TokenPro 选择目标模型并应用。
  后端 R55 继续拒绝不一致请求，不自动换模型或串到其他分组。

## 模型选择窗口黑边

- 无边框模型选择窗口改为透明原生窗口，由客户端抗锯齿绘制圆角背景。
- 不再用不透明矩形窗口叠加系统裁切，避免 macOS/Windows 缩放下圆角黑边。
- 不修改 Codex 自身窗口装饰。

升级后请重新选择一款生图模型、点击“应用模型”，并重启 Codex。
