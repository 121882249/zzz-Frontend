# TokenPro v1.2.97

- 配合后端 R54，启用 Codex 原生图片请求的独立模型/分组路由。
- 文本与图片不再共用静态分组 Header；每个文本模型保留自己的分组 slug，
  原生 Images 工具单独使用已应用的默认图片路由。
- 未选图片模型时，使用默认文本模型自身分组的生图工具能力，不借用其他分组。
- 不安装本地桥接、不启动本地服务、不生成旧桥接状态文件。
- 保留 v1.2.96 的官方切换清理、无回滚和独立后台会话修复。

上线顺序：后端 R54 → 真实 Codex 直连图片交付验收 → 发布本客户端标签。
升级后在 TokenPro 中重新点击“应用模型”，让 Codex 重新加载新路由配置。

默认生图使用首个已选生图模型；如在 Codex 中改选其他生图模型，须重新应用
对应路由，否则后台明确报模型/分组不一致，不静默串组。纯生图模型的后端
直派目前支持文生图；带图片编辑输入或仅 previous_response_id 的请求会明确
返回不支持，不丢弃输入后假装成功。

网站登录页“更多模型”徽标随后端 R54 网站构建发布，不属于桌面桥接组件。
