# TokenPro v1.2.96

本次仅发布 Codex 渠道切换、旧组件清理和会话修复，不宣称修复生图展示，也不启用待验收的 native-v1 生图协议。

- 切官方：正常退出 Codex，删除渠道 config.toml、已选模型及生成的模型映射，清理已退役的图片辅助进程/状态，然后启动 Codex。保留官方登录和 TokenPro 登录资料。
- 切 TokenPro：按已选模型与分组生成新映射，原子替换 config.toml，然后启动。不会因第二次模型列表拉取或本地模型模板读取失败而阻塞选择写入；真实文件系统写入失败仍报告错误。
- 不自动回滚。配置写入成功而启动失败时，保留新配置并提示手动启动。
- 全量会话设置修复在后台尝试，包括归档会话。单个失败只记录，不阻止启动、不恢复旧渠道，不重写聊天正文。再次切换时取消上一次修复任务。
- 旧图片辅助进程若无法终止，保留其状态并报告清理警告，不虚报清理完成，不启动新的图片桥接。
- CLI 读取自身配置，不再通过固定的 custom 参数覆盖官方模式。

验证：437 项自检通过；真实安装 Codex 的隔离历史测试通过双向 provider 修复、删除配置后官方修复、归档保留，原始会话记录字节未变。该历史测试不启动任何网络监听。

已知限制：生图直连的分组识别与原生图片交付仍在独立测试中。本版本保留 v1.2.95 的直连图片路由约定，不包含新的生图后端依赖。不得将本版本描述为“生图已完全修复”。
