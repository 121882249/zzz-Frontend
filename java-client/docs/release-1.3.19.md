# TokenPro v1.3.19

- Codex 桌面端“渠道配置”菜单新增“一键修复历史对话”，位置在“切换官方配置”下方。
- 修复操作由用户手动触发，把未归档和已归档任务中的旧 provider（如 `custom`、`tokenpro_direct`、`OpenAI`）统一迁移为 Codex 内置 `openai`。
- 修复时使用当前渠道模型，不发送聊天消息，不直接修改对话 JSONL 或 Codex SQLite；单个任务失败不会阻断其他任务。
- 日常 TokenPro/官方渠道切换继续保持轻量，不自动扫描或迁移历史对话。
- 2026-09-19 已通过 523 项客户端自检和安装版 Codex 隔离会话持久化验证。
